# Approved PentaMark visual contract

Authority: the author's PentaMark-Guia-Visual-Aprovado.zip, 18 October 2026. Guide Markdown SHA-256: cf64ad93487a84518d792ceb3451bb6ab512e0228be965d71a0a8133a930ba1a. Primary reference: 01-PRINCIPAL/interface-final-cantos-quadrados.png (1672 x 941). Private reference artwork is not republished here.

- Preserve the existing local-first collaborative Markdown application, not a screenshot-based replacement.
- Corners: 0px. Matte near-uniform graphite #181A1B/#17191A, restrained cyan. No olive camouflage, glowing decorative borders, particles or glass on the document.
- Document first. Left floating tree; collapse leaves only a pentagon opener without moving/rewrapping text, resetting scroll or expanded paths. Narrow screens use an overlay.
- Controls and contextual formatting appear on demand outside document layout. Opaque text on dark glass. Keyboard access, Escape, focus return, reduced motion and interruptible 140-200ms transitions. Never animate edited text geometry.
- Clicking formatted text in Live Preview must not reflow lines simply to expose syntax. Preserve source, caret, selection, editing, undo and saving. Keep explicit source access.
- Preserve existing shortcuts and user font/scale preferences. Technical typography must support Portuguese and long reading sessions. Concept-only Ctrl+Q is not a binding shortcut.
- Retain all modes, YAML, wikilinks, embeds, callouts, lists, tables, code, Mermaid, Kanban, assets, collaboration, permissions, conflicts, history, trash, sharing, MCP, desktop and mobile.
- Neural map and AI activity are on-demand views driven by real vault/events, with bounded work and truthful state. Pausing a feed is not cancelling an agent.
- The primary approved composition overrides historical concepts and game material references.
