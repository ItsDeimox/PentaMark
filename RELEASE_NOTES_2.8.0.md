# PentaMark 2.8.0 | Interface aprovada Pentagory

Nova interface grafite, totalmente quadrada e focada no documento, preservando os cofres Markdown locais.

## O que mudou
- Layout document-first, com superfícies foscas, ciano discreto e tipografia técnica.
- Navegação flutuante recolhível sem deslocar o texto.
- Busca rápida Ctrl+P, ferramentas sob demanda, formatação contextual e transições discretas.
- Correções de geometria no Live Preview, de atalhos, Escape e navegação; mantidos desfazer/refazer, cofre e colaboração.
- Preferências anteriores preservadas; versão local-first sem conta obrigatória.

## Downloads
- PentaMark-Desktop-2.8.0-Windows.exe: aplicativo portátil Windows x64, **não precisa de Node.js**.
- PentaMark-2.8.0-Pronto.zip: host local pré-compilado para PC, precisa de Node.js 20+.
- PentaMark-2.8.0-Mobile-Host-Android.zip: host para Android/Termux, precisa de Node.js no Termux.

## Atualização
Faça backup da pasta `vault`, feche a versão antiga e abra o executável novo. O programa não apaga o cofre anterior. O binário não tem assinatura de código, portanto o SmartScreen pode apresentar aviso.

## Ainda pendente
O mapa neural e o painel de atividade MCP em tempo real ainda não estão implementados. A ponte MCP já existente permanece disponível. Os testes de interface/edição automatizados não substituem testes completos do executável com dispositivos reais.
